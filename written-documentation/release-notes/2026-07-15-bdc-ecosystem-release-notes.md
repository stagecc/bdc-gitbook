# 2026-07-15 BDC Ecosystem Release Notes

2026-07-15 BDC Ecosystem Release Notes

### Introduction

The 2026-07-15 release marks the 25th update to the BDC ecosystem. This release introduces new features, including PIC-SURE “and” and “or” feature which allows researchers to build advanced queries.&#x20;

The 2026-07-15 data releases include the addition of 140 new datasets. See the Data Releases section below for more information.

### Significant new features&#x20;

The following new features were released this quarter to improve the researcher experience:

#### BDC Seven Bridges Platform (BDC-Seven Bridges)

* No significant new features to report for BDC-Seven Bridges&#x20;

#### BDC PIC-SURE Platform (BDC-PIC-SURE)&#x20;

* Build Cohorts with Advanced Queries: Researchers can now build advanced queries in PIC-SURE, combining logical operators (“and” and “or”) and grouping related variable-level filters. This tool enables researchers to create complex cohorts for analysis, visualize the variable distributions from these cohorts, and combine variable filters across multiple studies.&#x20;

#### BDC Terra Platform (BDC-Terra)&#x20;

* No significant new features to report for BDC-Terra&#x20;

#### BDC Gen3 Platform (BDC-Gen3)&#x20;

* No significant new features to report for BDC-Gen3&#x20;
