# 2 June 2026

## New Features and Improvements

* Researchers can now filter datasets by **Subject Type** using faceted search, making it easier to identify human and autopsy-based variable results.
* The **Advanced Query Builde**r now supports the **Variable Distributions Tool**, where bar charts and histograms are shown for individual variables, providing a quick way to inspect data distributions within a query.
